# 授权基准

测量日期为 2026-11-25。机器为 Intel Core i7-9700（8 逻辑核心），Windows 10 22H2，Moon CLI `0.1.20261104`、编译器 `v0.10.20+65efd5b93`。使用 native release，单进程依次运行，完整执行三轮。每轮每项采样 10 批，MoonBit 基准运行器自动决定每批迭代次数。表中数值为三轮各自均值的中位数，逐轮数据见 [CSV](benchmark-2026-11-25.csv)。

```powershell
moon bench --target native --release --no-parallelize -p Zcxssxx/biscuit -f authorization_bench_test.mbt
```

两个入口使用相同令牌、请求事实和允许策略。完整授权每次验签、检查 proof、解码并求值。复用授权在计时前运行一次 `prepare_with_key`，随后计量每次请求的求值耗时。签发测试令牌、解析调用方策略等准备动作均在计时外。链长含 authority，追加块各含一条操作检查。

| 令牌链 | 每次完整授权 | 已验签后的单次授权 |
| --- | ---: | ---: |
| Ed25519 1 block | 9.79 ms | 3.22 µs |
| Ed25519 4 blocks | 29.59 ms | 10.22 µs |
| Ed25519 16 blocks | 109.83 ms | 38.03 µs |
| P-256 1 block | 55.49 ms | 3.21 µs |
| P-256 4 blocks | 168.21 ms | 10.17 µs |
| mixed 4 blocks | 73.28 ms | 10.23 µs |

复用路径适用于同一可信根下、同一令牌的重复请求，每次仍执行令牌检查和调用方策略。首次验签开销计入完整授权列。服务端应按可信根和令牌内容维护缓存边界，在信任配置改变时失效，并在每次请求中提供最新时间和策略。结果仅适用于这台机器和这里的小型策略，不代表远程服务、并发吞吐或不同密码后端的性能。
