# 本轮全面检查与改进记录

基线：`c496834`。本轮检查覆盖协议入口、第三方块、授权查询、错误处理、例程、跨实现测试、CI 和维护文档。检查发现及处置如下。

| 范围 | 发现 | 本轮处置/边界 |
| --- | --- | --- |
| 第三方签名请求 | previous signature 未验证长度，旧 request 字段被静默忽略 | 拒绝不是 64-byte 的 previous signature、拒绝旧格式字段；与当前 v1 配置一致 |
| 资源边界 | 第三方签名输入及 contents 独立入口缺少统一大小检查 | 签名请求、block data、解析 contents 各限 1 MiB；新增拒绝测试 |
| 查询执行 | 每个连接绑定扫描全部事实，重复做来源过滤 | 每次查询先筛出可信来源并按谓词名建立索引，再检查参数数量；保留全部来源变体与 max_bindings 语义。未做性能基准，不报告提速倍数 |
| 回归测试 | 索引可能误合并同名事实的不同来源 | 测试单/多来源、错误 arity、无可见来源、连接结果与绑定数耗尽 |
| 示例错误处理 | 若干示例只打印失败，进程仍返回成功 | 出现非预期错误立即失败；授权示例错误放行 write 时失败；授权与事实检查示例加入 CI |
| 互操作证据 | 原测试仅比较 allow/deny | 新增结构化决策适配器，比较 allow/deny 对应策略索引、no-match 和 failed-check 类别；预期值独立由 Python 计算 |
| 差分可复现性 | 缺少生成用例及失败输入存档 | 固定 seed 20261119、32 组小型事实/规则/策略输入，记录 JSON 并由 CI 上传 artifact。尚不生成任意嵌套表达式或全部错误索引 |
| 测试运行可靠性 | 子进程缺少超时，Windows 默认编码可能无法读取诊断 | 互通子进程最多 180 秒，明确使用 UTF-8；CI job 最多 15 分钟，同分支旧运行取消 |
| 文档与接入 | 缺少维护者操作步骤和安全问题反馈说明 | 新增 CONTRIBUTING.md、SECURITY.md，更新兼容范围和测试统计 |
| 依赖可复现性 | Rust helper 未跟踪 Cargo.lock，Rust stable 会随时间变化 | 保留为已知限制；本轮不更换密码依赖、不宣称完整依赖锁定 |

未完成的长期项仍包括 P-256、密码独立审计、完整错误定位差分、请求级共享资源预算、wall-clock 超时和生产 RNG/撤销集成。此记录不等价于生产安全审计。

实际运行命令、通过数及 CI 链接见 [conformance.md](conformance.md)。
