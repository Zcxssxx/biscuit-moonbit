# 早期实施计划（归档）

本文记录本仓库早期以受限 Biscuit 子集为目标的计划。项目现已根据 MoonBit 黑客松初审意见完成扩展，早期范围不再代表当前实现状态。

当前项目定位、支持范围、实际测试结果和未覆盖边界以以下文档为准：

- [项目 README](../../README.md)
- [兼容性说明](../compatibility.md)
- [规范差距核对](../gap-analysis.md)
- [一致性与互操作记录](../conformance.md)

当前实现覆盖 Biscuit 当前 protobuf v3、Datalog 3.0–3.3 和 Ed25519 配置。P-256/secp256r1、旧外层 token 格式 v0/v1/v2、随机差分测试和 wall-clock 超时仍属于已知边界，详见上述兼容性说明。
